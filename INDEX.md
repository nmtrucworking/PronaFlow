## Top-Level Directories

- `apps/` - Frontend, backend, and desktop applications
- `services/` - Supporting services such as AI serving
- `configs/` - Shared configuration templates
- `docs/` - Technical documentation
- `scripts/` - Setup and utility scripts
- `storage/` - Temporary and uploaded files

## Configuration Files

- `.env.example` - Example environment variables
- `configs/environment.template` - Shared environment template
- `package.json` - Root scripts and workspace configuration
- `.gitignore` - Git ignore rules

## Application Areas

- `apps/backend/` - FastAPI backend
- `apps/frontend/` - React frontend
- `apps/electron/` - Desktop application
- `services/ai-serving/` - AI inference and model serving
